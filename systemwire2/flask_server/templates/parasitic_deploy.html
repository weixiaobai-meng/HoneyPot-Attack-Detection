注入配置

agent 会扫描该目录第一层的 .html/.htm 文件并注入脚本。正式告警链路为“页面 JS -> js/bot -> systemwire2 入库”。
选择内置五个 JS 时，后端会强制改为 inline，避免浏览器无法访问 agent 本地路径。

五个内置 JS 的职责

sessionToken.js: 生成当前访问会话标识。

client.min.js: 提供浏览器指纹库。

fingerprint.js: 采集浏览器、系统、GPU、插件、canvas 等指纹信息并提交到 ./info/。

network.js: 采集 WebRTC IP、WebSocket RTT 等网络侧信息。

bot.js: 采集鼠标、点击、键盘、滚动行为并提交到 ./bot-check。
