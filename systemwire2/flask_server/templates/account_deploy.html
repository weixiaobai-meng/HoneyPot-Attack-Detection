现在的部署规则

Xshell、FinalShell、OpenVPN 不再随便落到 agent 测试目录。

agent 会先自动扫描真实软件配置目录；扫描不到时，会创建该软件常见默认配置目录作为 fallback。

如果确实需要强制测试目录，可在探针主机设置 SYSTEMWIRE_ACCOUNT_OUTPUT_DIR 覆盖。

常见默认目录

Xshell: %USERPROFILE%\Documents\NetSarang Computer\7/8/9\Xshell\Sessions

FinalShell: %USERPROFILE%\.finalshell\conn、%LOCALAPPDATA%\finalshell\conn、%APPDATA%\finalshell\conn

OpenVPN: %USERPROFILE%\OpenVPN\config，找不到时再尝试 Program Files\OpenVPN\config

Linux: Xshell 不支持；FinalShell 使用 ~/.finalshell/conn；OpenVPN 优先 ~/.config/openvpn。

参数说明

Xshell: 需要主机、端口、用户名、密码。本地联调建议使用 127.0.0.1:22。

FinalShell: 需要主机、端口、用户名、密码。本地联调建议使用 127.0.0.1:22。

OpenVPN: 当前 agent 实现只需要 VPN 地址和端口。

命令格式: Xshell / FinalShell 使用 type:host:port:username:password，OpenVPN 使用 openvpn:host:port。
