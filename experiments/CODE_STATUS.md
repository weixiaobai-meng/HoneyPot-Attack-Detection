# 论文实验代码与研究内容

更新时间：2026-10-14。当前是可执行的研究框架，尚无完成的正式论文数据集或研究结论。
程序完备性不等于毕业资格，毕业要求以学校和导师的评价为准。

## 三项研究内容

1. **多蜜点异构告警的证据统一表示与关联图构建。** 将蜜点接入、告警采集、S-A-O三元组
   归入同一个研究内容；区分直接观测事件、证据支持的关联和弱推断关系。
   对应step1、step2，采集部署系统为支撑平台。
2. **来源证据与路径约束下的攻击关联图裁剪。** 将第一部分的证据属性输入GAT/DQN，
   学习冗余关系删留，同时保护直接事件证据与原图声明的可达关系。
   对应step3，规则/监督GAT使用相同约束作对照，分别评价约束和学习算法的贡献。
3. **基于裁剪证据图的大模型攻击行为与意图分析。** 比较原始告警、完整图、裁剪图三种输入，
   评价事实、TTP、阶段、意图及开销。对应step4、LLM运行器和独立金标准评估。

## 已实现的连接

`蜜点事件 → source_event_ids与evidence_basis → 图特征和训练奖励 → 可行动作 → 全图校验 → LLM输入`

- `step2_causal_graph/evidence.py`定义证据契约，事件边具有原始事件引用；关联边不自动视为因果。
- 正式构图禁用campaign/scenario及人工actor-group锚点。SSH客户端描述不再误当浏览器指纹。
- DQN输入增加直接观测、支持关联、来源事件数量特征。旧checkpoint维度不兼容，必须重新训练。
- `attack_origin_score`仍是规则基线的相关性评分，不是攻击者归因或概率，不以它代替来源证明。
- 受约束方法保护直接观测事件边，并按原图声明的路径组边界构造结构性可达约束；
  该约束只表示建模图的结构要求，不是攻击因果证明。无法确定边界的组被记录。
- 训练动作选择、探索和Bellman目标均排除非法删除动作；推理逐次校验，批量决策不会绕开校验。
- 分区结果合并后重新检查全图约束，保留必要的跨区边。算法不会以人工标签修复测试图。
- 剪枝输出同步更新节点、三元组、事件视图；仅从剩余边重建可达路径摘要，旧摘要不进入LLM。
- 部署链路实际使用裁剪图生成LLM输入；规则回退同样恢复直接事件与必要可达关系。
  如提示词窗口截断，则明确标记局部证据，不能沿用完整图的路径保持结论。

## 裁剪依据与边界

策略依据图结构、蜜点和关系类型、可观测关联属性及当前边掩码选择保留/删除。
训练奖励来自独立人工边标注，误删核心边惩罚较大，同时考虑压缩和来源证据。
这些标签不进入推理输入。直接事件保留是保守策略，因此不能保证任何图都取得较高压缩率。

原图可达关系保持不等于真实攻击因果保持。独立人工`path_gold`仅用于评价，不能用作动作约束。
缺乏独立路径金标准时不能因此声称已保护真实攻击链。
`complete_path_recall`评价具体人工路径的完整保留，与`required_paths_kept`分开报告。
替代路径可能保持可达性却不能保持原人工路径，两种指标会如实体现区别。

蜜点触发不一定都是恶意活动；授权扫描、运维等仍需人工判别。静态同IP、同账号、时间接近
不能证明同一攻击者；单靠现有观测无法恢复的真实对象流转关系，代码不会编造。

## 样本规模

场景按需加载，每个split缓存至多两张完整图；训练分区按需构造，不再常驻全数据集分区张量。
默认训练256边/推理512边分区，节点也随分区收缩；经验回放存分区索引和边掩码。
仍至少需要容纳单张原图、分区索引、模型和回放。该实现不是无限规模流处理系统。

可达性校验缓存可用路径见证；未触碰见证的删边不必重新搜索。最坏情况下仍可能
对每次候选删除检查多个约束，密集图/大量约束可能昂贵。
分区可减少神经网络前向规模，但不能消除全局校验成本。真实规模结果必须按节点、边、
约束数量和硬件报告，不可用微型诊断证明大规模性能。

## 正式实验与验收

- 正式数据必须具有原始日志、独立活动组划分、双人标注、分歧裁决、新版证据契约；
  测试场景还需人工路径金标准。旧图需重新构建，不能只补上版本号。
- 基准含9种方法：全保留、同压缩随机、规则、监督GAT、DQN、旧评分约束DQN、
  路径约束DQN、同约束规则、同约束监督GAT。
- 输出逐场景/seed结果、裁剪图、约束审计、路径指标、场景级置信区间、配对检验与Holm校正。
- 输出输入文件哈希、代码版本、脏工作树状态和运行环境，避免结果无法复核。
- LLM运行器默认只准备三组输入，显式`--execute`才请求服务。模型参数相同、顺序固定种子打乱；
  超预算拒绝整组，不静默截断；保留失败记录，不通过挑选重试隐藏失败。
- 对照准备阶段要求原始告警与完整图具有相同事件集合，裁剪图不得新增或修改边证据。
- LLM必须返回结构化事实和事件引用，引用缺失/未知时判为失败。引用存在仍不代表语义正确。
  自动事实/意图评分为规范化精确文本匹配，同义表达须人工复核；未匹配项不能直接认定幻觉。
  对应输出字段为`unmatched_fact_count`，不再使用含义过强的`hallucination_count`。
- `check_readiness`校验实验产物完整性，不能判断创新性、结论是否足够或学校是否准予毕业。
