## 运行命令

```bash
# 方式1: 一键运行完整流程
python run_full_pipeline.py --step all

# 方式2: 运行端到端实验
python run_experiment.py

# 方式3: 分步运行
python deployment/deploy_manager.py check    # 检查组件
python deployment/deploy_manager.py config   # 生成配置
python deployment/deploy_manager.py collect  # 收集告警
python main.py step1                         # 数据汇聚
python main.py step2                         # 因果图构建
python main.py step3 --mode train            # DQN裁剪
python main.py step4 --task intent_analysis  # Graph-to-Text
```
