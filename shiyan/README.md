# DQN 攻击图谱裁剪模块

## 功能说明

使用深度Q网络(DQN)对因果图进行智能裁剪，去除噪声边，保留核心攻击链路。

## 文件说明

```
shiyan/
├── dqn_model.py        # DQN模型 (GAT + Q-Network)
├── attack_env.py       # Gym环境类
├── graph_loader.py     # 因果图数据加载器 (新增)
├── train_real.py       # 真实数据训练脚本 (新增)
├── train.py            # 模拟数据训练脚本
├── evaluate.py         # 评估脚本
├── config.py           # 配置文件
└── checkpoints/        # 模型保存目录
```

## 使用方法

### 1. 准备数据

首先运行数据汇聚模块生成因果图：

```bash
cd ../data_collector
python main.py demo  # 生成演示因果图
```

### 2. 训练模型

```bash
cd ../shiyan

# 使用真实因果图数据训练
python train_real.py --mode train --graph ../data_collector/output/causal_graph.json --epochs 120

# 使用模拟数据训练（原始方法）
python train.py
```

### 3. 预测裁剪

```bash
# 使用训练好的模型裁剪因果图
python train_real.py --mode predict \
    --model checkpoints/dqn_real_best.pt \
    --graph ../data_collector/output/causal_graph.json \
    --output ../data_collector/output/pruned_graph.json
```

## 模型架构

```
输入: 节点特征 (N, 16) + 边索引 (2, E)
  ↓
GAT编码器 (4层, 残差连接)
  ↓
节点嵌入 (N, 64)
  ↓
边嵌入拼接 (E, 128)
  ↓
Q-Network (MLP)
  ↓
输出: [Q_keep, Q_prune] (E, 2)
  ↓
决策: argmax(Q) → 0=保留, 1=裁剪
```

## 奖励函数

| 情况 | 奖励 |
|------|------|
| 正确保留核心边 | +5.0 |
| 正确裁剪冗余边 | +1.0 |
| 错误裁剪核心边 | -10.0 |
| 错误保留冗余边 | -1.0 |
