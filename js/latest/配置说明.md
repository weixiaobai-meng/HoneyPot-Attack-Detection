# 项目配置说明文档

## 项目概述

本项目是一个**蜜罐/反爬虫检测系统**，由两个独立的 Go 模块组成：

| 模块 | 路径 | 功能 | 端口 |
|------|------|------|------|
| 主后端系统 | `bot/` | Bot 检测、设备指纹、蜜罐、代理检测 | 8080 |
| RTT 抓包服务 | `catchpacp/` | TCP 握手抓包计算 RTT | 9090 |

---

## 一、配置文件

### 1.1 `bot/config.json` - RTT 服务器地址

该文件配置主后端系统查询 RTT 数据的远程服务器地址。

```json
{
    "nginx_rtt_server": "http://192.168.253.137:9090"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `nginx_rtt_server` | string | RTT 查询服务器地址，**需按实际部署环境修改** |

**加载优先级**（从高到低）：
1. 环境变量 `NGINX_RTT_SERVER`
2. `config.json` 中的 `nginx_rtt_server`
3. 默认值 `http://192.168.253.1:9090`

> **注意**：在反向代理架构下，Bot 服务器抓不到客户端真实 IP 的 TCP 包，因此 RTT 改为从 nginx 服务器查询。

---

### 1.2 `bot/bots.json` - Bot 检测规则库

Bot 用户代理检测规则库，JSON 数组格式，每条规则包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `regex` | string | 匹配 User-Agent 的正则表达式 |
| `name` | string | Bot 名称 |
| `category` | int | 分类代码（见下表） |
| `url` | string | 官方文档/官网链接 |
| `producer` | object | 开发商信息（含 `name` 和 `url`） |

**分类代码对照表**：

| 代码 | 分类名称 | 说明 |
|------|----------|------|
| 0 | `search_engine` | 搜索引擎爬虫 |
| 1 | `web_crawler` | 网络爬虫 |
| 2 | `security_scanner` | 安全扫描器 |
| 3 | `seo_tool` | SEO 工具 |
| 4 | `monitoring` | 监控服务 |
| 5 | `analytics` | 分析工具 |
| 6 | `rss_reader` | RSS 阅读器 |
| 7 | `social_media` | 社交媒体 |
| 8 | `ai_bot` | AI 机器人 |
| 9 | `miscellaneous` | 其他 |
| 11 | - | 健康检查服务 |

如果 `bots.json` 加载失败，系统会使用内置的**默认规则**：
- `Googlebot`
- 通用 Bot 关键词匹配（`bot\|spider\|crawl\|curl\|wget\|python\|headless`）

## 三、部署检查清单

部署前请确认以下配置已按实际环境修改：

- [ ] `bot/config.json` 中的 `nginx_rtt_server` 地址正确
- [ ] `bot/handlers.go` 中的首页路径 `/var/www/front/index.html` 存在
- [ ] 防火墙开放 8080 和 9090 端口
- [ ] Go 1.24+ 已安装（主系统）
- [ ] Go 1.21+ 已安装（RTT 服务）
- [ ] `log/` 目录可写
- [ ] 如需 Kafka，取消 `session_manager.go` 中的注释并修改 Broker 地址
- [ ] 如需调整 Bot 阈值，修改 `bot/utils.go` 中的 `BotScoreThreshold`
